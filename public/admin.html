1 · TikFinity (LIVE events)

This app never connects to TikTok from the server. Likes, comments, gifts and joins come from the TikFinity desktop app on the PC that shows the overlay.

  1. Install TikFinity from tikfinity.zerody.one (the desktop app, not only the website).
  2. Open it and connect by username (don't sign in with your TikTok password).
  3. Go LIVE in TikTok LIVE Studio, then click connect in TikFinity if it hasn't already.
  4. Add the overlay URL below as a Link source at 1080 × 1920. Keep TikFinity open the whole time.
The badge turns green when the overlay can hear TikFinity. Use Reset counters when you start a new LIVE. Only one overlay should be running, or events will fire twice. The simulator in section 3 still works without TikFinity.
